Unlock Flow
Extract ZIP. In chrome://extensions enable Developer mode, select Load unpacked, and choose this folder containing manifest.json.
Keep this folder in place. Use the extension popup controls as needed.

Select Flow or Playground in the popup, then click the main Open button.
When access help is off, Enable and open turns it on in the same click.
The switch controls both services. Existing tabs are reused.
Playground: select Playground and click Open. The helper opens
/404?login_success=1&pli=1 and uses the app's internal Explore link.
If refreshing returns to the region page, the enabled helper retries this entry.
Catalog access is supported; game generation and account quotas are not verified.
On first use, complete Google's game profile setup yourself. The helper waits
while the dialog is open, then continues via the app's Explore navigation.
Выберите Flow или Playground и нажмите основную кнопку открытия.
«Включить и открыть» включает помощь и открывает сервис одним нажатием.
Переключатель общий для обоих сервисов. Уже открытая вкладка используется повторно.
Для Playground проверен вход в каталог;
создание игр и доступные лимиты аккаунта ещё не проверены.
При первом входе завершите настройку игрового профиля в окне Google.
Расширение ждёт закрытия этого окна, затем продолжает вход в каталог.

Updating / Обновление:
Archives include the version in their name, for example Unlock-Flow-v1.0.4.zip.
1. In the extension popup, check for updates and click Download Update.
2. Extract the ZIP into this SAME folder, replacing existing files.
3. Open the popup again and click Files replaced — restart. Refresh the service tab.
Do not remove the extension or load a second copy. Keep the manifest key unchanged.
If your old version has no restart button, reload its card in chrome://extensions once.

1. В окне расширения проверьте обновления и нажмите «Скачать обновление».
2. Распакуйте ZIP в ЭТУ ЖЕ папку с заменой файлов.
3. Откройте расширение и нажмите «Файлы заменены — перезапустить».

Не удаляйте расширение и не загружайте вторую копию.

на карточке расширения в chrome://extensions.
